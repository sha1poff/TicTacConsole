# TicTac
Общая часть лабораторных работ по прикладному программированию
---
## Этапы
[] 1. Создание консольной версии приложения с режимом игры PVP
[] 2. Преобразование класса игрока в абстрактный класс и создание наследников в виде человека и ИИ. Разработка ИИ на основе алгоритма Минимакс.
[] 3. Создание графического интерфейса на основе MFC.
[] 4. Привязка игровой логики к графическому интерфейсу.
